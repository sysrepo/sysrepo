# Docker setup

To try out the datastore plugins without installing the databases locally, you can use the docker compose setup via `docker compose -f docker/setup_dbs.yml up -d`. In order to connect to the databases you can run `bash docker/mongosh` for MongoDB and `bash docker/redis-cli` for Redis. For `make sr_clean` target to work, do not forget to add the correct client commands to the cmake configuration: `cmake -DCMAKE_BUILD_TYPE=Debug -DENABLE_DS_MONGO=ON -DDEFAULT_STARTUP_DS_PLG="MONGO DS" -DDEFAULT_RUNNING_DS_PLG="MONGO DS" -DDEFAULT_CANDIDATE_DS_PLG="MONGO DS" -DDEFAULT_OPERATIONAL_DS_PLG="MONGO DS" -DDEFAULT_FACTORY_DEFAULT_DS_PLG="MONGO DS" -DMONGO_CLI_CMD="docker;run;--rm;--network;host;mongodb/mongodb-community-server;mongosh" ..`. You will still need to have client libraries installed locally for the compilation!
